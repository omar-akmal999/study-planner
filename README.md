# منظم المذاكره

جدول مذاكرة أسبوعي بيتحسب حوالين مواقيت الصلاة والمدرسة والدروس، ويقدّم المادة اللي امتحانها قرّب أو اللي فاتتك.

موقع من ملف واحد (`index.html`) من غير أي تثبيت أو سيرفر. البيانات بتتحفظ في متصفح كل مستخدم.

## تشغيله محليًا
افتح `index.html` في أي متصفح.

## نشره على GitHub Pages
Settings ثم Pages، وفي Source اختار Deploy from a branch، والفرع `main`، والمجلد `/ (root)`.
